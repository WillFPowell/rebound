# REBOUND

An Expo app for injury-recovery check-ins, daily goals, and a weekly recap. Journal entries and goals are stored on the device. The peer-support preview uses fictional profiles. Supabase integration is planned.

## Run locally

Use Node.js 22.13 or later and an Expo Go build compatible with SDK 58.

```sh
npm ci
npx expo login
npm start
```

Sign in to the same Expo account on your iPhone. With both devices on the same Wi-Fi, scan the terminal QR code using the iPhone Camera.
